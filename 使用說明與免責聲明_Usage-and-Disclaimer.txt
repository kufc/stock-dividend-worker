1. 重要提醒（請先閱讀）
   Important notice (please read first)
--------------------------------------------------------------------

・整理前，請先備份重要的照片與影片。本程式會複製檔案，並在你確認之後
　移除原檔；任何處理檔案的軟體都有出錯的可能。
   Back up your important photos and videos before organizing. This
   program copies files and, only after you confirm, removes the
   originals. Any software that handles files can fail.

・「開始複製」只會複製，原檔完全不動。要不要處理原檔，是整理完成之後
　另外、可選的動作：確認複本沒問題後，才在「整理紀錄」使用「將這批
　原檔移到回收筒…」，原檔會被移到 Windows 的資源回收筒。
   "開始複製" (Start copying) only copies; your originals are left
   untouched. What to do with the originals is a separate, optional step
   after organizing: only after you have checked the copies, use "將這批
   原檔移到回收筒…" (Move these originals to the Recycle Bin) in the
   records page. Originals are moved to the Windows Recycle Bin.

・AI 的判斷可能出錯。按下任何確認視窗的確定之前，請先看過完整清單。
   The AI can be wrong. Read the full list before you click OK in any
   confirmation window.

・使用本程式，即表示你已閱讀並接受第 10 節的免責聲明。
   By using this program you acknowledge that you have read and accepted
   the disclaimer in Section 10.

2. 這個程式做什麼
   What this program does
--------------------------------------------------------------------

・AI 先看過資料夾裡的照片與影片，告訴你「這看起來像什麼」；你確認或
　修改分類後，程式依分類把檔案複製到資料夾，並重新命名。
   The AI first looks at the photos and videos in a folder and suggests
   what each one looks like. After you confirm or change the categories,
   the program copies the files into per-category folders and renames
   them.

・分類可以自訂，也可以直接使用中文名稱。
   Categories are customizable, and Chinese names work directly.

・辨識在你自己的電腦上進行。有 NVIDIA 顯示卡時使用顯示卡加速，否則
　使用 CPU（較慢）。
   Recognition runs on your own computer. It uses an NVIDIA GPU when one
   is available; otherwise it uses the CPU (slower).

・支援的圖片：JPG、PNG、HEIC／HEIF、WEBP、GIF、BMP、TIFF。
　支援的影片：MP4、MOV、AVI、MKV、WMV、M4V、WEBM、FLV、3GP、MTS、MPG。
   Supported images: JPG, PNG, HEIC/HEIF, WEBP, GIF, BMP, TIFF.
   Supported videos: MP4, MOV, AVI, MKV, WMV, M4V, WEBM, FLV, 3GP, MTS,
   MPG.

3. 系統需求
   System requirements
--------------------------------------------------------------------

・Windows 10 或 11。本文的操作步驟以 Windows 為準。
   Windows 10 or 11. The steps in this file assume Windows.

・64 位元的 Python 3.10 以上，建議 3.12。安裝 Python 時，請勾選
　「Add python.exe to PATH」與「tcl/tk and IDLE」。
   64-bit Python 3.10 or newer; 3.12 is recommended. When installing
   Python, check "Add python.exe to PATH" and "tcl/tk and IDLE".

・記憶體 8 GB 以上（使用「高精準」模型建議 12 GB 以上）。
   At least 8 GB of RAM (12 GB or more is recommended for the "accurate"
   model).

・硬碟空間約 12 GB；整理時另外需要與被整理照片相同大小的空間，因為
　程式是先複製。
   About 12 GB of disk space, plus free space equal to the size of the
   files being organized, because the program copies first.

・NVIDIA 顯示卡為選配，建議安裝最新的驅動程式。
   An NVIDIA GPU is optional; the latest driver is recommended.

4. 安裝與解除安裝
   Installation and uninstallation
--------------------------------------------------------------------

・在 ZIP 檔上按右鍵「全部解壓縮」，放到一般資料夾（例如
　C:\AI媒體分類器）。不要直接在 ZIP 裡雙擊執行，也建議避開 OneDrive
　同步資料夾。
   Right-click the ZIP file and choose "Extract All" into a normal
   folder (for example C:\AI-Media-Sorter). Do not run anything from
   inside the ZIP, and avoid OneDrive-synced folders.

・雙擊 install.bat。如果出現「Windows 已保護您的電腦」，按「其他資訊」
　再按「仍要執行」。
   Double-click install.bat. If Windows shows "Windows protected your
   PC", click "More info" and then "Run anyway".

・第一次安裝會從網路下載數 GB 的檔案（PyTorch 與 AI 模型），需要時間
　與網路流量。
   The first installation downloads several GB from the internet
   (PyTorch and the AI model). It takes time and uses data.

・看到「安裝完成」後，雙擊 start.bat 開啟程式。
   When you see the installation-complete message, double-click
   start.bat to open the program.

・解除安裝：先關閉程式，再雙擊 uninstall.bat。它會列出每一項會做什麼、
　多大，你輸入 Y 之後才開始。預設只移除程式運作環境（.venv 資料夾，
　含 Python 套件與 PyTorch）；你的設定與分類清單、整理紀錄、AI 模型檔案
　都要各自同意才會移除。
   Uninstall: close the program, then double-click uninstall.bat. It
   lists what each step does and how big it is, and only starts after
   you type Y. By default it removes only the runtime environment (the
   .venv folder with the Python packages and PyTorch); your settings and
   category list, the organize records, and the AI model files are
   removed only if you agree to each one separately.

・解除安裝不會動到：你的照片與影片、整理輸出的資料夾（例如「已分類」）、
　資源回收筒，以及 logs\復原移除 裡的檔案（沒有資源回收筒時，被搬開的
　複本放在那裡，是你的檔案）。程式資料夾本身也不會被刪除，不需要時請
　自行刪除整個資料夾。
   Uninstalling never touches: your photos and videos, the output
   folders (for example "已分類"), the Recycle Bin, and the files in
   logs\復原移除 (copies moved aside when no Recycle Bin was available;
   they are your files). The program folder itself is not deleted
   either; delete the whole folder yourself when you no longer need it.

・AI 模型檔案放在 Hugging Face 的快取（預設是 %USERPROFILE%\.cache\
　huggingface），可能跟其他程式共用，所以要另外同意才會移除，而且只會
　移除本程式使用的兩個模型，不會動快取裡的其他東西。
   The AI model files live in the Hugging Face cache (by default
   %USERPROFILE%\.cache\huggingface), which may be shared with other
   programs. They are therefore removed only with your separate consent,
   and only this program's two models are removed; nothing else in the
   cache is touched.

・移除整理紀錄後，就無法再用本程式「移除這次建立的複本」或「將這批原檔
　移到回收筒」（檔案本身不受影響）；有還沒處理完的紀錄時，解除安裝程式
　會提醒你。
   Once the organize records are removed, this program can no longer
   "移除這次建立的複本" (remove the copies) or "將這批原檔移到回收筒"
   (move the originals to the Recycle Bin) for those runs; the files
   themselves are not affected. The uninstaller warns you when there are
   records that have not been finished.

・解除安裝程式只會刪除清單裡的項目，每一項在刪除前都會再確認位置；
　連結（捷徑式資料夾）只移除連結本身；程式還開著時會拒絕執行。任何一項
　失敗都會如實回報，不會假裝成功。
   The uninstaller only deletes the items on its list and re-checks the
   location of each one before deleting. A link (shortcut-style folder)
   is removed as a link only, and the uninstaller refuses to run while
   the program is open. Any failure is reported honestly instead of
   being hidden.

5. 使用步驟
   How to use
--------------------------------------------------------------------

・第 1 步「選擇資料夾」：選擇要整理的資料夾（可勾選「包含子資料夾」），
　看過圖片、影片的數量後，按「開始辨識」。
   Step 1, choose the folder: pick the folder to organize (you can tick
   "include subfolders"), check the number of images and videos, and
   click "開始辨識" (Start recognition).

・第 2 步「確認分類」：左邊是檔案清單（縮圖、建議分類、處理狀態，可搜尋
　與篩選），右邊是大預覽與候選分類。點候選分類只是選取；按 Enter
　（「確認並看下一個」）才會確認。1／2／3 選擇候選、S 略過、Ctrl+Z
　撤回上一次確認。
   Step 2, confirm categories: the left side lists the files (thumbnail,
   suggested category, status; searchable and filterable) and the right
   side shows a large preview with candidate categories. Clicking a
   candidate only selects it; nothing is confirmed until you press Enter
   ("確認並看下一個", confirm and go to the next). 1/2/3 pick a candidate,
   S skips, Ctrl+Z undoes the last confirmation.

・標示「需檢查」的檔案，表示模型沒有把握，請自己看過再選；模型給的分數
　只是參考，不代表判斷正確的機率。
   Files marked "需檢查" (needs checking) are ones the model is unsure
   about; please look at them yourself. The model's score is only a hint
   and is not the probability that it is right.

・批次操作（套用分類、採用建議、略過）只會處理你明確選取的列。
   Batch actions (apply a category, accept suggestions, skip) only affect
   the rows you have explicitly selected.

・第 3 步「預覽整理結果」：確認輸出位置（預設是來源資料夾裡的「已分類」）
　與檔名規則（預設保留原檔名），檢查整理前後對照與所需空間。預設只整理
　你已確認的檔案。按「開始複製」之前，不會建立或改動任何檔案。
   Step 3, preview the result: check the output location (by default
   "已分類" inside the source folder) and the naming rule (original names
   are kept by default), and review the before/after table and the space
   needed. By default only files you confirmed are organized. Nothing is
   created or changed until you click "開始複製".

・複製過程中可以按「完成目前檔案後停止」；已複製好的檔案會保留。
   While copying you can click "完成目前檔案後停止" (stop after the
   current file); files already copied are kept.

・第 4 步「完成」：顯示結果。有失敗的檔案時，畫面會用白話說明原因與可以
　怎麼做，處理後按「重試」即可，已複製好的不會重做；技術細節預設收起來。
   Step 4, done: shows the result. If some files failed, the screen
   explains in plain words what happened and what you can do, and you
   can click the retry button; files already copied are not redone.
   Technical details are collapsed by default.

・打開輸出資料夾，檢查分類結果。
   Open the output folder and check the results.

・之後（可選）：在「整理紀錄」頁選一批整理，可以按「移除這次建立的複本…」
　（不滿意時）或「將這批原檔移到回收筒…」（確認複本沒問題後）。每次都會
　列出完整清單再確認一次，而且預設按鈕是「取消」。
   Afterwards (optional): in the records page ("整理紀錄") pick a batch
   and use "移除這次建立的複本…" (remove the copies created by that run,
   if you are not satisfied) or "將這批原檔移到回收筒…" (move the
   originals to the Recycle Bin, once you have checked the copies). Each
   action shows the full list and asks again, and the default button is
   "取消" (Cancel).

6. 檔案的處理方式與保護機制
   How files are handled and the safeguards
--------------------------------------------------------------------

・整理只會複製。程式不會覆蓋任何既有檔案；檔名重複時會自動換成下一個
　編號。
   Organizing only copies. The program never overwrites an existing
   file; when a name is taken it moves on to the next number.

・每一次移除（移到回收筒的原檔，或移除這次建立的複本）之前，都會確認
　「另一份內容逐位元組完全相同的檔案仍然存在」，而且一律送到資源回收筒。
   Before every removal (originals moved to the Recycle Bin, or copies
   created by a run being removed), the program checks that another file with byte-for-byte
   identical content still exists, and it always sends the file to the
   Recycle Bin.

・移除前，檔案會先暫時改名（檔名會多一個「(整理前)」或「(複本)」標記）。
　在 Windows 上，直到送出為止，其他程式無法寫入這兩份檔案；如果任何
　一份正被其他程式開著寫入，程式會回報「使用中」並保留檔案。
   Before removal the file is temporarily renamed (a "(整理前)" or
   "(複本)" tag is added to its name). On Windows, other programs cannot
   write to either file until it has been sent off; if either file is
   open for writing in another program, the program reports "in use" and
   keeps the file.

・原檔被移到資源回收筒後，檔名會帶有「(整理前)」；從資源回收筒還原
　之後，請自行把檔名改回來。
   After an original is moved to the Recycle Bin its name carries the
   "(整理前)" tag; after you restore it from the Recycle Bin, please
   rename it back yourself.

・把原檔移到回收筒之後，就不能再用「移除這次建立的複本」；要找回原檔，
　請到資源回收筒還原。
   Once the originals have been moved to the Recycle Bin, "移除這次建立的
   複本" (remove the copies) can no longer be used for that batch; to get
   an original back, restore it from the Recycle Bin.

・整理紀錄（logs 資料夾）只是操作的依據，沒有防竄改的能力，不是安全
　機制。真正的保護是上面的「另一份相同內容」檢查，以及確認視窗中的
　完整清單。
   The organize log (the logs folder) is only a working record. It
   cannot detect tampering and is not a security mechanism. The real
   protections are the "another identical copy" check above and the full
   list shown in the confirmation window.

・掃描時會跳過資源回收筒、System Volume Information、NAS 縮圖資料夾
　（@eaDir）與系統檔。
   Scanning skips the Recycle Bin, System Volume Information, NAS
   thumbnail folders (@eaDir) and system files.

7. 已知限制
   Known limitations
--------------------------------------------------------------------

・本程式主要是在非 Windows 的環境中開發與自動測試。Windows 專屬的行為
　（資源回收筒、檔案使用中、禁止寫入）只有少量的專屬測試，可能還有
　沒被發現的差異。
   This program was developed and automatically tested mainly in a
   non-Windows environment. Windows-specific behavior (Recycle Bin,
   files in use, write locking) has only a few dedicated tests and may
   still contain undiscovered differences.

・「禁止其他程式寫入」的保護只有 Windows 上有；其他系統只能做到改名
　與再次比對。
   The "block other programs from writing" protection exists only on
   Windows; other systems only get the rename and the second comparison.

・網路磁碟機（NAS）在 Windows 上通常沒有資源回收筒，檔案送出時可能
　被直接刪除（刪除前仍會確認另一份相同內容存在）。
   Network drives (NAS) usually have no Recycle Bin on Windows, so a
   file may be deleted outright when it is sent off (the check for
   another identical copy still applies).

・雲端同步的資料夾（例如 OneDrive）在複製與改名期間可能同時進行同步，
　建議先暫停同步。
   Cloud-synced folders (for example OneDrive) may sync while files are
   being copied or renamed; consider pausing synchronization first.

・分類太少時，AI 仍會把每個檔案歸到「最像」的那一類，不相關的照片也會
　被硬塞進去；建議至少設定 3 個分類，並留意「需檢查」標示。
   With too few categories the AI still files every item under the
   "closest" one, so unrelated photos get forced into a category. Use at
   least 3 categories and pay attention to the "需檢查" (needs checking) marks.

・影片是平均抽出幾張畫面來判斷，可能漏掉只出現一瞬間的內容。
   Videos are judged from a few frames sampled evenly, so content that
   appears only briefly may be missed.

・並未在所有型號的顯示卡、所有 Python 版本與所有檔案格式上測試過。
   The program has not been tested on every GPU model, every Python
   version or every file format.

8. 資料、隱私與網路連線
   Data, privacy and network use
--------------------------------------------------------------------

・照片與影片的辨識都在你的電腦上進行，程式本身不會上傳你的檔案。
   Recognition of photos and videos happens on your computer. The
   program itself does not upload your files.

・安裝與第一次使用時，會連線到網路下載元件：Python 套件（PyPI）、
　PyTorch（download.pytorch.org）與 AI 模型（Hugging Face）。這些網站
　可能會看到你的 IP 位址與下載請求，並適用它們各自的隱私政策。
   Installation and first use connect to the internet to download
   components: Python packages (PyPI), PyTorch (download.pytorch.org)
   and the AI model (Hugging Face). Those sites may see your IP address
   and download requests, and their own privacy policies apply.

・程式會在你的電腦上保存：settings.json（設定）、categories.json
　（分類）、logs 資料夾（整理紀錄、錯誤紀錄與主控台輸出）。整理紀錄
　含有檔案的完整路徑；回報問題時若要貼出紀錄，請先檢查其中是否有個人
　資訊。
   The program stores these on your computer: settings.json (settings),
   categories.json (categories) and the logs folder (organize logs,
   error logs and console output). Organize logs contain full file
   paths; if you paste logs when reporting a problem, check them for
   personal information first.

・AI 模型會下載到使用者資料夾底下的 .cache\huggingface。
   The AI model is downloaded to .cache\huggingface under your user
   folder.

・本程式不寫入 Windows 登錄檔，也不建立捷徑、服務或開機自動啟動項目。
　它留在電腦上的東西只有：程式資料夾（含 .venv）、AI 模型快取，以及
　pip 下載套件時 pip 自己的快取（可用 pip cache purge 清除）。
   The program does not modify the Windows registry and does not create
   shortcuts, services or startup entries. The only things it leaves on
   the computer are the program folder (including .venv), the AI model
   cache, and pip's own download cache from installing packages (which
   you can clear with pip cache purge).

9. 疑難排解（簡要）
   Troubleshooting (brief)
--------------------------------------------------------------------

・雙擊 start.bat 沒有反應：程式可能已經開著（請看工作列）；也可以查看
　logs 資料夾裡的 error.log 與 console.log。
   Nothing happens when you double-click start.bat: the program may
   already be open (check the taskbar); you can also look at error.log
   and console.log in the logs folder.

・顯示卡沒有啟用：更新 NVIDIA 驅動程式後，重新執行 install.bat。
   The GPU is not used: update the NVIDIA driver and run install.bat
   again.

・顯示卡記憶體不足：在「設定」把「每批處理張數」調低，或改用「標準」
　模型。
   GPU out of memory: lower "batch size" in Settings, or switch to the
   "standard" model.

・完整說明請看 README.md。
   See README.md for the full documentation.
