HOLD-OUT SET - DO NOT USE FOR TUNING.
This set was collected on 2026-11-21, AFTER all default prompts and thresholds were fixed. It exists only for a
one-off final evaluation of the default categories. Never tune prompts, thresholds or rules against it; if that
ever happens it is no longer a hold-out set and a new one has to be collected.

Sources of the hold-out images behind embeddings_holdout_standard.npz / embeddings_holdout_accurate.npz
(1,176 images in 23 groups: 13 default categories + 10 "belongs to no default category" groups).
All images come from public, non-gated datasets on the Hugging Face Hub. None of the datasets of the dev set
(photo_sources.txt) is used, nor any repackaging of the same underlying data (no COCO, FFHQ, WIDER FACE,
cats_vs_dogs, SUN397, Food-101, Oxford Flowers, Caltech-101, ScreenSpot, RVL-CDIP, CORD, ImageNet/ImageNette ...).
Images were re-saved as JPEG (RGB, longer side <= 1024 px) into <extra-dir>/<group>/NNN.jpg and are NOT committed
(only the embeddings are). The whole set is rebuilt by
    python tests/manual/collect_holdout.py --out <extra-dir>
which pins every dataset to a commit hash (REV in the script), and was checked to reproduce the files
byte-for-byte. <extra-dir>/manifest.tsv lists group, file, source key (dataset:file#row) and kept/removed.
The embeddings were made with
    python tests/manual/dump_embeddings.py --preset <standard|accurate> --only-extra --per-class 0
        --extra-dir <extra-dir> --out tests/manual/embeddings_holdout_<preset>.npz
In the .npz the n-th KEPT file of a group (sorted by name) is called x_<group>_<n>.jpg, so its number differs
from NNN.jpg wherever an earlier file of the group was removed; image_groups holds the group name.

Selection discipline
- Every pick is random with a fixed seed, random.Random("20261121:<group>:<source>"), using only dataset labels
  and metadata (rules below). The classifier was never run on any image before the selection was final.
- Then every group was looked at on a contact sheet, and only images that are mislabelled, unrecognisable, or
  genuinely ambiguous between two default categories (or between "none" and a default category) were deleted -
  the same rule as the dev set. Nothing was deleted for looking "hard". Deleted files are listed by name in
  REMOVED in collect_holdout.py; counts and reasons are given per group below.
- Changes made to the selection rules after seeing contact sheets (all before any model was run, all made on
  metadata only, none aimed at difficulty):
  * 花草植物: a plain random pick of the Pl@ntNet shard gave ~12 species (the shard is sorted by species and
    long-tailed), so it was replaced by "at most 2 images per species, then 60 at random".
  * 螢幕截圖: the first Rico config picked (default "data/") turned out to hold colour-block semantic
    annotations, not screenshots; replaced by the config with the real screenshots.
  * 迷因梗圖: not-lain/meme-dataset (20 images) was dropped completely because it holds meme TEMPLATES without
    any caption (plain photos of a dog, a baby ...; the dev set excluded uncaptioned templates for the same
    reason); the MemeCap pick was enlarged from 40 to 60 instead.
  * 城市建築: about half of the Oxford/Paris images were not buildings (see below), so the Intel part was
    enlarged from 8 to 15 per class.
  * none_art: the WikiArt shard has no abstract paintings, so 14 (not 11) per remaining genre.
"License" is what the dataset card / its license tag states; "not stated" = the card has no license tag.

== Skipped / dropped ==
- not-lain/meme-dataset: collected, then dropped as a source (uncaptioned templates, see above).
- none_handwriting / none_map / none_logo were considered and not collected (handwritten pages are too close to
  文件收據; no suitable labelled map or logo photo set was looked for further).
- Tried and rejected before any image was selected: ferrariedhgs/Nature-Landscape (synthetic images),
  Kaludi/food-category-classification-v2.0 (may be derived from Food-101), Places365 and ADE20K (too close to
  SUN397), the Flickr30k rule on one shard only (too few hits, so all 9 shards are used).

== Known limits ==
- "Expected = none" is debatable for part of the none groups, and the evaluation should be read with that in
  mind:
  * none_sports: almost every image shows one or several people doing sport (a user might accept 人像 / 合照);
    a few show horses or a hand-cycle.
  * none_art: paintings and sketches whose SUBJECT is people, a landscape, a building or a horse (genre labels
    are loose; e.g. a few landscape sketches and two portrait drawings are in). Nothing was removed here.
  * none_aerial: aerial tiles of buildings, harbours with boats, car parks, forest, beach, river.
  * none_wildlife: includes cows, a goose, a turkey and one toy rhinoceros; coyote / fox / wolf look like dogs
    and big cats like cats (kept on purpose - they are not pets).
  * none_indoor: a few rooms contain a person or shop goods (clothes, shoes, toys, books).
  * none_product overlaps the KIND of objects of the dev set's none_misc (chair, lamp, mug, stapler), from a
    different dataset.
- 人像: the LFW half are small (250 px) press photos of public figures, mostly men, often with other people
  partly visible at the edge; the VOC half are candid full-body shots, including babies and people seen from
  behind.
- 合照: includes candid groups and very large groups (teams, classes); some Flickr30k images show 2-3 people.
- 貓 / 狗: pet-breed photos, one clear animal each (an easy set).
- 風景 / 城市建築: the Intel images are only 150x150 px and LHQ only 256x256 px; LHQ has no labels, so its
  cleaning relied on the eye; some 風景 images contain a road, a flag pole or a warning sign; 城市建築 contains
  skyline views, building details, street scenes with cars and people. The Oxford/Paris part is small (21).
- 美食: the Chinese-food images are low resolution; the snack images include raw fruit, packaged candy and food
  being prepared.
- 花草植物: only 36 species (thistles, pelargoniums, ferns, St John's wort ...), all outdoor phone photos; some
  show mostly leaves or sparse weeds on soil. No bouquets, trees or house-plant product shots.
- 交通工具: about 9 per class; several bicycles and motorbikes are parked close-ups; a few buses and trains are
  seen only partly; boats range from a rubber dinghy to a cruise ship and warships.
- 螢幕截圖: Android screenshots are old (Android 4-7 look); several desktop screenshots are dark, nearly empty
  windows or mostly wallpaper. No chat screenshots, no games, no Chinese-language UIs.
- 文件收據: receipts are all Malaysian shop receipts on a white scan background; the documents are clean
  rendered PDF pages (no photographed paper, no handwriting, no ID cards / invoices photographed by phone).
- 動漫插畫: Japanese-style illustrations only (no western cartoons, no manga pages, no TV frames).
- 迷因梗圖: English Reddit memes only (no Chinese-language memes, no stickers).
- The by-eye cleaning was done by one reviewer on 200-px thumbnails.
