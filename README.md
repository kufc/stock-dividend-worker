# AI 媒體分類器（AI Media Sorter）

> 📄 **使用前請先閱讀**：[使用說明與免責聲明（中英對照）](使用說明與免責聲明_Usage-and-Disclaimer.txt)　｜　Please read first: [User Guide and Disclaimer (Chinese / English)](使用說明與免責聲明_Usage-and-Disclaimer.txt)

雙擊就能用的桌面程式：AI 先幫你看一遍資料夾裡的**照片與影片**，告訴你「這看起來像什麼」，
你確認（或修改）分類後，**預覽整理結果**，再一鍵**依分類複製到資料夾**（可選擇是否重新命名）。
原檔一律不動；要不要處理原檔，是整理完成之後另外、可選的動作。

- 使用 NVIDIA 顯示卡（CUDA）加速；沒有顯示卡也能用 CPU 執行（較慢）
- 分類可以**自訂、直接用中文**（例如：貓、寶寶、旅行、收據）
- 所有辨識都在**你自己的電腦**上完成，照片不會上傳到任何地方

## 運作流程

程式分成四個步驟，畫面上方的步驟列會顯示目前在哪一步（可以點已經完成的步驟回頭看）：

```
① 選擇資料夾 ──▶ ② 確認分類 ──▶ ③ 預覽整理結果 ──▶ ④ 完成
   看到圖片／影片    左邊清單＋右邊大預覽    輸出位置、檔名、     結果、失敗重試、
   數量，開始辨識    逐一確認或批次處理      整理前後對照         之後（可選）的處理
```

整理後的結果（預設保留原檔名；選「分類＋序號」時會像下面這樣）：

```
手機照片\
└─ 已分類\
   ├─ 貓\        貓_001.jpg、貓_002.heic、貓_003.mp4 ⋯
   ├─ 風景\      風景_001.jpg ⋯
   └─ 螢幕截圖\  螢幕截圖_001.png ⋯
```

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 / 11 |
| Python | 3.10 以上（建議 **3.12**），從 [python.org](https://www.python.org/downloads/) 安裝，安裝時勾選 **Add python.exe to PATH** |
| 顯示卡（選配） | NVIDIA 顯示卡，並安裝最新版驅動程式；RTX 50 系列也支援 |
| 記憶體 | 8 GB 以上；「高精準」模型建議 12 GB 以上 |
| 硬碟空間 | 約 12 GB（PyTorch 約 5 GB＋AI 模型 1.5～5 GB＋暫存）；整理時另需與照片相同大小的空間（先複製） |

## 安裝（只需要做一次）

1. 下載這個專案（GitHub 綠色的 **Code → Download ZIP**；或用 `git clone`）
   - 在 ZIP 上按右鍵 →「**全部解壓縮**」，**不要**直接在 ZIP 裡雙擊
   - 建議放在一般資料夾（例如 `C:\AI媒體分類器`），避開 OneDrive 同步資料夾
2. 雙擊 **`install.bat`**
   - 若出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」
   - 它會自動：
     - 挑選合適的 Python 版本（優先 3.12），建立獨立環境（`.venv` 資料夾，不影響其他程式）
     - 偵測你的 NVIDIA 顯示卡與驅動程式，安裝對應 CUDA 版本的 PyTorch（已裝對就略過）
     - 檢查視窗元件、下載 AI 模型並測試顯示卡是否正常運作
3. 看到「安裝完成！」就可以關閉視窗

> 第一次安裝需要下載數 GB 的檔案，請耐心等候。

## 使用方式

雙擊 **`start.bat`** 開啟程式（第一次使用若還沒安裝，會自動先執行安裝）。

1. **選擇資料夾**：按「選擇資料夾…」（可勾選「包含子資料夾」），畫面會顯示找到幾張圖片、幾支影片、
   幾個不支援而會被略過的檔案，以及 AI 模型是否需要下載。確認後按「開始辨識 N 個檔案」
2. **確認分類**：左邊是檔案清單（縮圖、建議分類、處理狀態），右邊是大預覽與候選分類
   - 清單可以搜尋，也可以篩選：全部／待確認／需檢查／建議較明確／已確認／已略過／讀取失敗／某個建議分類
   - 點候選分類**只是選取**；按 **Enter**（或「確認並看下一個」）才會確認，並自動跳到下一個待確認的檔案
     - 按 **1／2／3** 選擇候選，按 **S**（或「略過此檔」）略過，按 **Ctrl+Z**（或「撤回上一次確認」）撤回
     - 都不是：在「都不是？選其他分類」輸入名稱搜尋，或按「新增分類…」
   - 標示**「需檢查」**（橘色）= 模型沒有把握，這種檔案不會預先幫你選好，請自己看過再選；
     「建議較明確」只代表模型分數較高，**不代表一定正確**，所以介面不把分數稱為「準確率」
   - 批次操作（套用分類、採用建議分類、略過選取的）**只會處理你明確選取的列**（Ctrl／Shift 多選，Ctrl+A 全選）；
     想一次確認一批：先用篩選（例如「建議較明確」）→ Ctrl+A → 「採用建議分類」，之後仍可撤回
   - 辨識還沒跑完也可以先確認或略過，結果出來後不會蓋掉你的選擇
   - 全部確認完，右邊會顯示「分類確認完成」
   - 視窗比較窄時，清單與預覽會改成兩個分頁；中間的分隔線可以拖曳，下次開啟會記住比例
3. **預覽整理結果**：不會動到任何檔案，只是讓你看清楚接下來會發生什麼
   - 顯示**真正的輸出路徑**、需要的磁碟空間與剩餘空間，以及「整理前後對照」表
   - 檔名：預設**保留原檔名**；也可以選「分類＋序號」「日期＋分類＋序號」或自訂格式，對照表會即時更新
   - 預設只整理**已確認**的檔案；有「建議較明確」但還沒確認的檔案時，可以勾選一起整理
   - 按「開始複製 N 個檔案」才會開始；複製中可按「完成目前檔案後停止」，已複製好的會保留
4. **完成**：顯示成功與失敗的數量
   - 有失敗的檔案時，會用白話說明「發生什麼事、可以怎麼做」，處理後按「重試」，已複製好的不會重做；技術細節預設收起來
   - 按「開啟輸出資料夾」檢查結果
   - 「之後的處理（可選）」：原檔都還在原位，不處理也沒關係。想處理時，到「整理紀錄」頁選一批整理：
     - **移除這次建立的複本…**：不滿意時使用，複本移到資源回收筒，原檔不受影響
     - **將這批原檔移到回收筒…**：確認複本沒問題後才用。確認視窗會列出來源資料夾、輸出資料夾與**每一個**檔案
       （可搜尋），來源跟你目前選的資料夾不同時會顯示警告，預設按鈕是「取消」
     - 原檔會移到 Windows 的**資源回收筒**，檔名會多一個標記（例如 `IMG_1234 (整理前).jpg`），還原後改回即可
     - 只有跟複本內容完全相同的原檔才會移除；複本不見或被改過的，原檔會保留
     - 原檔正被其他程式開著時不會移除，會列為失敗，關掉那個程式後再做一次即可
     - 確認之後、執行之前，如果紀錄檔被改變，程式會拒絕執行並請你重新檢視

畫面上方還有「整理紀錄」「分類設定」「設定」「說明」。「說明」會打開使用說明與免責聲明。

### 檔案安全

整理採用「**先複製、確認後再移除原檔**」，設計目標是：**不論哪個環節出錯，都不會讓任何一份照片從磁碟上消失。**

- 整理只會複製，原檔不動；撞名就自動換下一個編號，絕不覆蓋任何既有檔案
- 複製時先寫成不會撞名的暫存檔，完整寫完才改成正式檔名；磁碟滿了也不會留下不完整的檔案
- 每一次刪除（復原時移除複本、移除原檔）都要求「**另一份內容逐位元組相同的檔案仍然存在**」，
  而且刪除一律送到資源回收筒。所以就算整理紀錄（`logs\整理紀錄_*.csv`）寫到一半、被修改或被放回舊的，
  最壞情況只是某個檔案沒被處理，不會遺失資料
- 刪除的順序是「比對 → 先在同一個資料夾內改名 → 用『禁止其他程式寫入』的方式開啟**兩份**檔案 →
  握著它們再比對一次、送資源回收筒 → 最後才放開」：
  - 從比對到送出為止，要移除的那一份和留下的那一份都不能被任何程式修改
  - 任何一份已被其他程式（例如照片編輯器、同步程式）開著寫入時，程式回報「使用中」並保留檔案
  - 改名後，照原路徑存檔的程式只會產生新檔，不會動到要送出的那一份
  - 限制：這個「禁止寫入」的保護只有 Windows 有；在其他系統上只做得到改名與第二次比對
  - 限制：網路磁碟機（NAS）在 Windows 上通常沒有資源回收筒，送出時可能會直接刪除（刪除前仍會確認另一份相同內容存在）
- 確認視窗會列出這次要處理的**每一個**檔案（可搜尋、可捲動，不省略），標明哪些會處理、哪些不符合條件而保留，
  以及來源與輸出資料夾；紀錄的來源資料夾跟你目前選擇的資料夾不同時，會顯示警告
- 你確認的清單，就是實際執行的清單：確認之後紀錄檔若被改變，程式會拒絕執行
- **整理紀錄不是安全邊界**：紀錄沒有簽章，來源與輸出資料夾也寫在紀錄裡，能修改紀錄的人可以一起修改。
  真正的保護是「另一份內容相同的檔案必須存在」、一律送到資源回收筒，以及確認視窗的完整清單——
  按下確認前請看一下清單
- 紀錄檔無法讀取或是空的時，會給出說明並可把它移到旁邊（改名為 `無法讀取_…`），以便處理更早的紀錄
- 兩個路徑其實指向同一個檔案（大小寫不同、目錄連接點）時，不會被當成「另一份」
- 沒有安裝資源回收筒套件（send2trash）時：移除複本會把複本搬到 `logs\復原移除\`，移除原檔則完全不動作
- 圖片像素數上限為 3 億（約涵蓋 200MP 手機照片）；超過的圖片會顯示為「無法讀取」，避免記憶體不足
- 掃描時會跳過資源回收筒、`System Volume Information`、NAS 縮圖（`@eaDir`）與系統檔

### 「AI 還看到這些」

除了你設定的分類，AI 也會從內建的 150 個常見詞彙中找出畫面裡的東西（例如「沙發」「夕陽」「聊天截圖」），
點一下就能把它**新增為分類**，AI 會立刻重新判斷所有檔案（不需要重新讀檔，只要幾秒鐘）。

## 分類設定

按「分類設定」可以新增、刪除、排序分類。每個分類有：

- **名稱**：也是資料夾名稱與檔名的一部分
- **給 AI 的描述**（選填，每行一個）：中文或英文皆可；英文描述通常最準，例如 `a photo of a cat`

預設分類：人像、合照、貓、狗、風景、城市建築、美食、花草植物、交通工具、螢幕截圖、文件收據、動漫插畫。

分類清單存在 `categories.json`，想備份或分享給別人時複製這個檔案即可。

## 重新命名樣式

| 代碼 | 意義 | 範例 |
| --- | --- | --- |
| `{分類}` | 分類名稱 | 貓 |
| `{序號}` | 同一分類內依拍攝時間排序的編號 | 001 |
| `{日期}` | 拍攝日期（照片 EXIF → 影片資訊 → 檔案修改時間） | 20240503 |
| `{原檔名}` | 原本的檔名（不含副檔名） | IMG_2031 |

例如 `{分類}_{日期}_{序號}` → `貓_20240503_001.jpg`。撞名時會自動換下一個編號，不會覆蓋任何檔案。

## 設定

| 設定 | 說明 |
| --- | --- |
| AI 模型 | **自動**：顯示卡記憶體 6 GB 以上、系統記憶體 12 GB 以上用「高精準」，否則用「標準」 |
| 影片取樣畫面數 | 每支影片平均擷取幾張畫面來判斷（預設 8） |
| 需要確認的門檻 | 模型分數低於此值的項目標成「需檢查」（預設 50%）；這個分數不等於判斷正確的機率 |
| 每批處理張數 | 一次送進顯示卡的張數；出現記憶體不足時請調低 |

| 模型 | 首次下載 | 特色 |
| --- | --- | --- |
| 標準（xlm-roberta-base-ViT-B-32） | 約 1.5 GB | 速度快，CPU 也跑得動 |
| 高精準（xlm-roberta-large-ViT-H-14） | 約 5 GB | 準確度明顯較高，建議搭配 NVIDIA 顯示卡 |

兩者都是 [LAION](https://laion.ai/) 的多語言 CLIP 模型（透過 [OpenCLIP](https://github.com/mlfoundations/open_clip)），
支援中文分類名稱。模型只在第一次使用時從 Hugging Face 下載，存放在 `%USERPROFILE%\.cache\huggingface`
（想放到其他磁碟，可設定環境變數 `HF_HOME`）。

AI 一定會把檔案歸到「最像」的分類，所以分類太少時，不相關的照片也會被硬塞進去。
建議至少設定 3 個分類，需要時加一個「其他」；跟所有分類都不像的檔案會標成「需檢查」提醒你確認。

## 支援格式

- 圖片：JPG、PNG、HEIC／HEIF（iPhone）、WEBP、GIF、BMP、TIFF
- 影片：MP4、MOV、AVI、MKV、WMV、M4V、WEBM、FLV、3GP、MTS、MPG

## 解除安裝

關閉程式後，雙擊 **`uninstall.bat`**。它會先列出每一項會做什麼、多大，你輸入 **Y** 才會開始。

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 程式運作環境（`.venv`：Python、PyTorch 等套件，約數 GB） | 移除 | 解除安裝的主體；要再用時重新執行 `install.bat` |
| 設定與分類清單（`settings.json`、`categories.json`） | 保留，詢問後才移除 | 移除後重新安裝會回到預設分類 |
| 整理紀錄與錯誤紀錄（`logs\` 裡的檔案） | 保留，詢問後才移除 | 移除後，無法再用本程式移除複本或處理原檔（檔案本身不受影響）；有還沒處理完的紀錄時會提醒 |
| 本程式用的 AI 模型檔案（Hugging Face 快取） | 保留，詢問後才移除 | 快取可能跟其他程式共用，只會刪本程式的兩個模型資料夾 |

**絕對不會動**：你的照片與影片、整理輸出的資料夾（例如「已分類」）、資源回收筒、`logs\復原移除` 裡的檔案
（沒有資源回收筒時被搬開的複本，是你的檔案），以及程式資料夾以外的其他東西。程式資料夾本身也不會被刪除，
不需要時請自行刪除整個資料夾。

安全設計：

- 只會刪清單裡的項目，每一項在刪除前都會再確認「確實在程式資料夾底下、名稱完全符合」；不接受自訂刪除路徑
- 找不到本程式的檔案、或資料夾是磁碟根目錄／使用者資料夾時拒絕執行；程式還開著時也拒絕執行
- 連結（符號連結、目錄連接點）只移除連結本身，不會跟著刪掉它指向的內容
- 任何一項失敗都會如實回報並以非 0 結束，不會假裝成功；可以關掉占用檔案的程式後再執行一次
- 進階：`python -m media_sorter.uninstaller --dry-run` 只列出會做什麼；`--yes` 不詢問（預設只移除 `.venv`），
  搭配 `--remove-settings`、`--remove-logs`、`--remove-model` 指定其他項目

本程式不寫入登錄檔，也不建立捷徑、服務或開機自動啟動項目；留在電腦上的只有程式資料夾、AI 模型快取，
以及 pip 自己的下載快取（可用 `pip cache purge` 清除）。

## 疑難排解

| 狀況 | 解決方式 |
| --- | --- |
| 辨識時狀態列顯示「CPU（未偵測到可用的 NVIDIA 顯示卡）」 | 更新 NVIDIA 驅動程式後，重新執行 `install.bat` |
| 雙擊 `start.bat` 沒反應 | 程式可能已經開著（看工作列）；或查看 `logs\error.log`、`logs\console.log`，也可以在命令提示字元執行 `.venv\Scripts\python -m media_sorter` 看錯誤訊息 |
| 安裝時說「程式正在執行中」 | 先關閉 AI 媒體分類器視窗再執行 `install.bat` |
| 安裝時說缺少視窗元件（tkinter） | 重新執行 Python 安裝程式 → Modify → 勾選「tcl/tk and IDLE」 |
| install.bat 顯示找不到 Python | 安裝 Python 時要勾選「Add python.exe to PATH」 |
| PyTorch 安裝失敗 | Python 版本可能太新，改裝 Python 3.12 後刪除 `.venv` 資料夾再執行 `install.bat`（安裝程式會優先選 3.12） |
| 顯示卡記憶體不足（out of memory） | 「設定」中把「每批處理張數」調低，或改用「標準」模型 |
| 某些影片「無法讀取」 | 檔案可能損毀、編碼特殊，或是純錄音檔；可手動選分類或略過 |
| 顯示「AI 計算結果異常（NaN）」 | 少數顯示卡的半精度計算不穩定，程式會自動改用 fp32；若仍出現請改用「標準」模型 |

## 專案結構

```
install.bat              安裝（雙擊）
start.bat                開啟程式（雙擊）
uninstall.bat            解除安裝（雙擊）
requirements.txt         Python 套件清單
media_sorter/
  app.py                 視窗程式：步驟流程、辨識與複製的背景工作、狀態管理
  views.py               四個步驟與外框的版面（可捲動區域、左右分割／分頁）
  dialogs.py             確認視窗、整理紀錄、放大檢視、分類設定、設定、問題說明
  theme.py               外觀（配色、字型、按鈕樣式，依 Windows 縮放調整大小）
  analysis.py            辨識流程：多執行緒讀檔 → 顯示卡批次推論
  classifier.py          AI 模型（多語言 CLIP）載入與向量比對
  media.py               圖片／影片讀取、影片抽幀、拍攝日期、縮圖
  organizer.py           複製、重新命名、紀錄、復原與移除原檔
  config.py              預設分類與設定
  vocabulary.py          「AI 還看到這些」的內建詞彙
  installer.py           偵測顯示卡並安裝對應的 PyTorch
  uninstaller.py         安全的解除安裝程式（只刪清單內的項目）
tests/                   自動化測試
```

使用者資料（不會上傳到 git）：`categories.json`、`settings.json`、`logs\`（整理紀錄 CSV、錯誤紀錄、主控台輸出）。

## 開發

```bash
python -m venv .venv
.venv\Scripts\pip install torch torchvision -r requirements.txt pytest
.venv\Scripts\python -m pytest
```

測試使用假的模型（依顏色分類），不需要下載 AI 模型或顯示卡；`tests/test_app.py` 會實際開啟視窗跑完整流程，
`tests/test_regressions_*.py` 是對抗測試找到的問題所對應的回歸測試。
